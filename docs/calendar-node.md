# 日历选择器节点

节点类型为 `calendar`，无需 AI。先添加点击日期输入框的网页节点，打开日历弹层；随后添加日历节点，选择弹出的容器（支持 iframe），填写日期。

配置：`target` 与其他 DOM 节点相同；`mode` 为 `single` 或 `range`；`date` 为目标/开始日期；`endDate` 为区间结束日期。日期格式 `YYYY-MM-DD`，日期时间配置见 [日期时间节点](calendar-datetime.md)，支持 `{{start_time}}`、`{{end_time}}` 等表达式。

单日期模式也可操作区间控件的一端；若控件要求分别打开开始与结束弹层，可用两个“点击输入框 → 日历选择器”组合。区间模式在同一弹层依次选择开始和结束日期。

规则识别：中文/数字/英文年月标题、标准日期 title/data-date/aria-label、日期表格、prev/next/year/super 等按钮标记。优先当前月份日期格，拒绝禁用与歧义日期。选中标记或输入框值更新用于验收。非标准控件可能需要增加规则，不能保证覆盖所有自定义日历；无法识别时走失败出口。

日历容器 selector 应尽量稳定；`body > div:nth-child(17)` 随弹层顺序变化可能失效，建议使用日历弹层类名并确保只匹配一个可见容器。

图标导航自校验：结合按钮/后代图标的 class、aria-label、title、SVG use 引用和箭头符号识别方向及月/年跨度；无标记图标仅在日历标题区域尝试。每次点击重新读取月份，按实际变化学习方向；无变化则换候选，未靠近目标则尝试恢复原年月，再换按钮。每轮最多尝试 8 个候选、恢复最多 4 次；恢复不能验证时立即失败，不继续选日期。翻页前后年月、恢复过程会进入节点运行日志（失败也保留），不依赖 AI。
