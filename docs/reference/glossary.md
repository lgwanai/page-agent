# 术语表

| 术语 | 说明 |
| --- | --- |
| 工作流 Workflow / Script | 由节点和连线组成、可保存复用的流程；Script 是部分兼容接口中的名称 |
| 节点 Node | 一次网页操作、请求、判断式检索、等待或容器步骤 |
| 连线 Edge / Port | 选择成功、失败、完成或旧版遍历路径 |
| 草稿 Draft | 当前编辑内容，可本机恢复，尚未更新正式工作流 |
| 实例 instanceId | 一个已连接 Chrome 插件实例的身份 |
| workflowId | 工作流 UUID，执行接口不用名称代替 |
| key | 指定工作流在本机的访问密钥 |
| Selector | 用于定位网页 DOM 的 CSS 选择器，也作为网页操作类型的英文名 |
| locator | 保存元素稳定身份和多个定位候选的信息，用于稳健定位与修复 |
| frame | 页面内的文档作用域；iframe 的数字 ID 可能变化 |
| 参数 data | 本次调用传入、按开始节点声明映射的值 |
| context | 已执行节点的输出上下文；单节点调试可显式提供 |
| output / outputs | 输出节点的最终值与按名称汇总的值 |
| ok | 执行状态，不能单独等同业务成功 |
| businessOk | 输出节点显式标记的业务结果 |
| verification | 单步操作的实际状态和验收信息 |
| diagnostic | 错误码、发生阶段、上下文及处理建议 |
| MCP | Agent 客户端与本机工具服务之间的协议 |
| stdio | 客户端通过进程标准输入输出与 MCP 服务通信 |
| Bridge | 本机服务与 Chrome 扩展之间的桥接；不是公网服务地址 |
| Provider | 智能分析节点所用的模型服务配置 |
| Action | 兼容旧版的已保存操作集合；当前界面不提供新建保存入口 |

## 阅读 JSON 时的区别

`node.name` 是业务节点名，`kind` 是固定类型；中文/英文显示标题不是新的 JSON 字段。修改显示文案不会改变 `kind`，重命名业务节点则需要同步检查表达式。

`schemaVersion: 1` 表示工作流交换文件格式，扩展本地库的 `schemaVersion: 2` 是另一层数据结构，不应互换。
