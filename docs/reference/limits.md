# 限制速查

以下为 0.10.66 / MCP 0.10.17 源码中的当前约束，不是目标网站允许的业务上限。系统总步数等限制可能先于单节点限制生效。

| 范围 | 当前约束 |
| --- | --- |
| 浏览器页面 | Chrome 最低版本由 manifest 指定为 125；操作目标为 HTTP/HTTPS 网页 |
| 工作流规模 | 全图含子流程最多 500 个节点；每个图作用域最多 1000 条连线 |
| 执行预算 | 单次流程最多 1000 个节点执行步；子流程最多嵌套 8 层 |
| 连线 | 每个输出端口只连接一个后续；不能跨子流程边界 |
| 执行并发 | 同一插件实例同一时间一个工作流 |
| 等待 | 固定或随机区间 0–60000 毫秒整数 |
| 监控 | 超时 100–3600000 毫秒；检查间隔 100–10000 毫秒 |
| 请求 | 超时 100–300000 毫秒；HTTP/HTTPS；GET/HEAD 无请求体 |
| 原生弹窗 | 超时 100–300000 毫秒；alert 只支持确定 |
| 分页 | `maxPages` 1–5000；单次翻页超时 100–30000 毫秒；稳定等待 0–10000 毫秒 |
| 检索 | 可设置结果数量上限 1–500 |
| 数据表 | 当前原生 DOM 表格；最多 5000 行、200 列、50000 单元格；单元格文本最长 32767 字符，整体字符预算约 5 MB |
| Excel 文件 | 生成文件不超过 10 MB |
| 邮件附件 | 合计约 10 MB，按 Base64 大小估算 |
| 路径上传 | 单次 1–20 个文件；不支持目录；旧 20 MB 限制已取消，仍遵循网站和浏览器约束 |
| 标签 | 最多 10 个，每个 1–30 个字符 |
| 运行历史 | 每流程最近 20 条、合计最多 200 条、总计约 2 MB |
| 画布历史 | 当前编辑会话最多保留 50 次历史快照，不是跨会话版本库 |

## 不支持的替代关系

- 路径上传不能代替操作系统文件窗口自动化。
- 原生弹窗节点不能处理网页 HTML 弹层、浏览器权限窗口或 HTTP 认证框。
- 请求节点不自动携带网站 Cookie，也不代替页面登录流程。
- 数据表节点不自动抓取分页和虚拟滚动未加载的全部数据。
- 成功点击、文件已选入、邮件已接受分别不等于业务提交、上传完成、邮件送达。
- AI 分析、DOM 定位和运行草稿不能代替明确的结果验收或正式保存。

超出约束时应缩小处理批次、按页设计流程或选择更合适的节点，不建议仅提高某一个局部上限。
