# 本地练习与示例

所有示例仅操作本地页面或读取本地 JSON，不提交真实业务。需要源码目录的 Node 环境；只有扩展 ZIP 时，可在自己的测试网页按录制教程操作，或请维护者提供练习服务。

## 启动

```bash
npm run docs:serve
```

打开 `http://127.0.0.1:4180/examples/practice.html`；停止服务使用 `Ctrl+C`。如更换端口，需要同步修改导入流程的开始网址、frame URL 与请求 URL。

## 示例清单

| 文件 | 需要的输入 | 预期结果 |
| --- | --- | --- |
| [问候练习](greeting.page-agent.json) | 文本 `姓名`，如“张三” | 页面和 output 显示“你好，张三” |
| [JSON 请求](request.page-agent.json) | 无 | output 为 [演示数据](sample-response.json) 中的对象 |
| [对象列表循环](loop.page-agent.json) | 对象列表 `记录` | 按顺序更改页面，最终保留最后一项问候结果 |

循环输入示例：

```json
[{"姓名":"张三"},{"姓名":"李四"}]
```

在侧栏“导入 JSON”后核对开始节点网址，再运行。工作流 ID 冲突时生成新 ID；练习文件不含访问密钥，MCP 需要使用本机导入后生成的密钥。

## 练习页还提供什么

- confirm、prompt 按钮：练习浏览器弹窗节点的确定、取消和输入。
- 本机文件选择框：仅显示选入文件的名称和大小，不上传到服务端。
- 原生数据表：练习 DataTable 读取和 Excel 输出。

静态服务拒绝 POST 写入，因此文件选入不代表上传完成。这与业务网站中需要检查上传回执的情况相同。
