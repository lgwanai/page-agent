# 截图、邮件与智能分析

## 截图 · Screenshot

可选择可视窗口、整页滚动拼接、框选区域，返回 PNG 文件对象。整页超长时可能返回多个分段文件，应检查完整性元数据；页面变化或拼接未完成不会作为完整结果输出。

框选坐标使用文档 CSS 坐标，页面布局变化后应重新框选。运行结果可下载文件，后续通过独立变量引用文件对象：

```text
{{页面截图}}
```

文件不能与固定文本拼接。MCP 独立截图工具 `capture_page_screenshot` 还支持 Selector 或坐标区域，详见 [MCP 编排参考](../mcp-authoring.md)。

## 发送邮件 · Email

在邮件节点展开本机邮箱配置，填写 SMTP 服务需要的信息。节点本身配置收件人、主题、正文和附件变量；SMTP 账号不写进节点 JSON。

正文可以是文本或变量。附件每行一个独立文件输出引用，例如：

```text
{{页面截图}}
{{数据表.excel}}
```

正文独立引用文件对象时会作为附件处理。附件合计约 10 MB；邮件发送需要可用的本机 MCP 邮件服务。成功表示发送服务器已接受，不保证收件箱最终送达。结果未知时检查发件记录，不自动重发。

## 智能分析 · AI

只有该节点会调用配置的模型进行分析；普通定位、检索、循环、分页、请求和日历不需要模型。

1. 点击顶部“配置 AI”，填写 Base URL、模型或 Endpoint ID、API Key。
2. 测试连接并保存本机配置。
3. 在节点填写指令，按需添加网页 Selector、前置节点或固定文本输入。
4. 单节点调试，检查结构化 output、判断结果和实际动作，再连接后续节点。

使用兼容的聊天完成接口；可选择内置 Provider 或配置自定义兼容地址。具体可用模型、额度与服务支持以实际服务端配置为准。

网页输入可读取单个或多个元素。给模型的输入应与任务相关；若配置模型进一步操作 Selector 或调用旧 Action，应核对其动作范围。模型输出不是业务验收的替代品，后续仍可使用监控/输出确认实际结果。

模型密钥独立保存在本机，工作流导出不包含该全局 Key；节点指令、固定输入与显式填写的内容仍会导出。数据流向见 [数据与权限](../guide/data-and-permissions.md)。
