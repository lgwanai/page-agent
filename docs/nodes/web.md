# 网页操作与定位

## 选择控件

从新增菜单选择“网页操作 / Selector”，进入页面选择状态。悬停观察高亮，点击真实业务控件创建节点。选择状态会抑制页面原有操作，避免选取时误提交；退出选择后再正常操作网页。

选中画布节点并展开属性，根据控件类型选择可用事件。定位信息包含 CSS Selector、元素语义身份以及 frame 文档信息；录制与手动选取使用同一套定位规则。

## 常见事件

| 目的 | 事件与配置 |
| --- | --- |
| 填写输入框 | `input`，值可使用 `{{参数}}` |
| 点击/双击 | `click` / `doubleClick` |
| 原生下拉 | `select`，按实际选项设置 |
| 勾选/取消 | `check`，核对执行后的 checked 状态 |
| 聚焦与离焦 | `focus` / `blur`，以及对应 focusin/focusout |
| 悬停/移开 | `hover` / `mouseLeave` |
| 键盘组合 | `pressKey`，配置 key、可选 code 和修饰键 |
| 滚动、右键、长按、拖动 | 按目标控件选择对应事件 |
| 提交与重置 | `submit` / `reset`；先确认是否应对真实业务生效 |

控件类型决定可选事件，不是所有元素都适用所有操作。页面事件和最终值会进行相应校验；点击事件被接收不等于服务器业务已经完成。

网页节点的键盘事件不保证操作系统快捷键、浏览器快捷键或真实剪贴板权限。画布撤销快捷键是编辑器功能，两者不同。

## 稳健定位与旧流程升级

定位优先考虑稳定唯一 ID、name、稳定上层 ID 范围内的精确文本/value，再使用语义属性和样式；仅在缺少身份时保留位置候选。数字层级或 class 不应成为唯一长期依据。

运行旧工作流时，会尽量依据已有元素身份修复并保存升级结果；没有足够信息、匹配多个候选或业务 URL 不一致时，不会猜测第一个控件。属性中的自动修复记录可查看旧定位信息。

直接手改 CSS 表示使用该配置的检索语义；带变量的动态 Selector 和多元素读取不能当作唯一身份自动改写。

## iframe

`frameId` 是当前文档编号，重建后可能变化。保存的文档 URL、业务参数和稳定名称帮助定位当前 frame；业务 ID、站点或路径变化需要检查，而不是全部忽略。

MCP 先列出 frame，再读取或选择目标文档。选错 frame 时，即使 CSS 本身有效也无法找到正确控件。

## 按本机路径上传

文件上传属于网页操作节点的 `upload` 事件，并非独立的请求节点。Selector 可指向文件框、关联 label 或包含唯一文件框的容器。

路径值支持：

```text
{{文件路径}}
```

或每行一个绝对路径，也可以通过列表参数传入字符串数组。Windows JSON 示例：

```json
["C:\\资料\\报告.pdf", "C:\\资料\\说明.txt"]
```

需要可用的本机 MCP 服务，路径属于运行该服务的电脑。单次 1–20 个文件，遵循控件的 accept 和 multiple；目录、重复路径、无效文件会拒绝。插件不再限制为 20 MB，实际大小由网站、浏览器和可用资源决定。

文件选择会触发网页 input/change，可能立即上传。步骤中 `filesSelected: true` 仅确认选入文件；服务器上传是否完成应由网站回执、监控或检索节点确认。系统文件选择窗口不属于此功能的自动操作范围。
