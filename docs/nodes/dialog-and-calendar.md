# 弹窗与日历

## 浏览器弹窗 · Browser Dialog

用于浏览器原生 `alert`、`confirm`、`prompt` 和离开页面确认框 `beforeunload`。一个节点同时负责“监听 → 触发控件 → 按配置应答 → 核验关闭结果”。

| 类型 | 确定 | 取消 |
| --- | --- | --- |
| alert | 关闭提示 | 不适用 |
| confirm | 网站得到 true | 网站得到 false |
| prompt | 网站得到填写的文本 | 网站得到 null |
| beforeunload | 允许离开 | 留在页面 |

选择触发控件，配置触发事件、类型、确定/取消、文字匹配和超时。prompt 确定时可配置输入文字。取消也是成功执行，因为它是按配置完成的应答。

已有点击节点可在属性中转换为弹窗节点，保留 ID 与定位信息。不要前置另一个相同触发点击，否则弹窗阻塞后再监听会来不及。

网页内 HTML 弹层使用网页操作节点；系统文件选择器、权限窗口和 HTTP 认证窗口不属于此节点范围。beforeunload 是否弹出取决于浏览器与网页用户交互条件。

详情见 [浏览器原生弹窗](../browser-dialog.md)。练习页提供 confirm 和 prompt 按钮，可用于测试取消与输入。

## 日历选择器 · Calendar

适用于可识别的 DOM 日期/日期时间控件。一般先用网页操作点击输入框打开弹层，再添加日历节点选择完整弹层容器，配置单日期或区间。

| 配置 | 示例 |
| --- | --- |
| 日期 | `2026-11-01` |
| 日期时间 | `2026-11-01 10:11:12` |
| 开始/结束 | 独立变量 `{{开始时间}}`、`{{结束时间}}` |
| 单个输入框 | 只配置需要操作的一端 |

区间控件需要两端日期时，不要只填写结束值。部分网站有独立的时间列表与确定按钮，应检查实际输入框最终值，而非只看弹层高亮。

执行会根据实际年月变化确认导航方向，并检查最终日期/时间；禁用、歧义或无法识别的日期会失败。日期节点不调用 AI，也不能保证覆盖所有自绘控件。

精确配置与时间支持见 [日期时间节点](../calendar-datetime.md)。
