# 请求 · HTTP Request

请求节点用于调用链接/API，返回 Text 或 JSON。它由扩展后台发送，不通过网页点击，也不自动继承网站 Cookie；可通过请求头提供服务需要的认证值。

## 操作步骤

1. 新增“请求”，连接到需要执行的路径。
2. 展开属性，填写完整 HTTP/HTTPS URL。
3. 选择方法与返回类型；需要 JSON 请求体时设置 `Content-Type`。
4. 按需填写 JSON 对象形式的请求头、文本或变量请求体和超时。
5. 单节点调试查看返回值，再连接输出节点将结果作为工作流输出。

Text 直接返回字符串；JSON 保留对象、数组、数字、布尔值或 null 类型。JSON 模式下空响应和无效 JSON 会失败，不会默默退回文本。

## 练习：读取本地 JSON

启动 `npm run docs:serve` 后，导入 [请求练习 JSON](../examples/request.page-agent.json)。流程从本地练习页开始，请求：

```text
http://127.0.0.1:4180/examples/sample-response.json
```

输出应包含 `message: "请求练习成功"` 和记录列表。后续可用 `{{读取练习数据.output.records.0.name}}` 访问第一条记录名称。

## 结果与失败

成功要求 HTTP 2xx 且按指定类型读取完成。HTTP 状态错误、网络问题、超时和解析失败走失败出口。超时包含读取响应体；停止运行会中止当前请求并阻止后续节点。

服务器可能在连接中断前已处理写入，因此请求不自动重试。请求节点的 URL、请求头或正文若硬编码令牌，也会出现在导出的工作流中。

方法、字段、POST 示例与 MCP 说明见 [请求详细配置](../http-request.md)。
