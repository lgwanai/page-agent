# 安装与升级

当前文档对应扩展 **0.10.77**、本机 MCP 服务 **0.10.21**。Chrome 最低版本为 **125**，操作目标为 HTTP/HTTPS 网页。

## 选择安装方式

| 方式 | 适用场景 | 包含内容 |
| --- | --- | --- |
| 扩展 ZIP | 录制和编辑网页操作、手动录屏，或已有 MCP 环境 | Chrome 扩展；不包含 Node、MCP 服务或网站账号 |
| 完整便携包 | 获得维护者提供的 Windows/macOS 完整包 | 扩展、对应架构的 Node、MCP 服务、生产依赖与 Setup |
| 源码构建 | 开发、自行部署、Linux 环境 | 在本机安装依赖并生成扩展和 MCP 服务 |

工作流异步录屏、路径上传和邮件还需要相应的本机服务。扩展 ZIP 不会同时安装该服务。版本应以侧栏实际加载的扩展和 MCP 面板的服务信息为准。

## 安装完整包

1. 完整解压到固定、可写的目录；Mac 根据 Apple 芯片或 Intel 选择包，Windows 根据 x64 或 ARM64 选择包。
2. 首次运行 `Setup.cmd`（Windows）或 `Setup.command`（Mac）。Setup 注册当前用户的 Chrome 本机启动器，并将本机路径写入包内扩展配置。
3. 打开 `chrome://extensions`，开启“开发者模式”，加载包内 `extension/`。
4. 打开侧栏核对 **0.10.77**，在 MCP 面板点击 **配置并启动**；插件内无需手动导入 JSON、填写路径或复制安装命令。
5. 需要 Agent 调用时，在模型客户端另行导入 Setup 生成的 `page-agent-mcp.json` 并启用服务。Setup 不会替用户修改其他客户端配置。

完整包无需再安装 Node、npm 或执行构建。移动目录或使用另一个新包目录后，重新运行该目录的 Setup，并更新客户端配置。Windows 真机录制与非 UTF-8 系统代码页下中文安装路径仍待验收，详见 [跨系统部署](../cross-platform-mcp.md)。

## 只安装扩展 ZIP

1. 将 ZIP 完整解压到固定目录，保留 `manifest.json` 和全部资源。
2. 打开 Chrome 扩展管理页，选择“加载已解压的扩展程序”，加载直接包含 `manifest.json` 的目录。
3. 从工具栏打开 Page Agent，核对侧栏实际版本。
4. 打开要操作的网页，确认登录账号正确；音视频录制需在目标页点击工具栏图标并取消播放器静音。

源码构建加载 `dist/`，完整包加载 `extension/`。扩展不从 ZIP 压缩文件直接运行。本机启动器未安装时，也可由 MCP 客户端启动已有的源码服务。

## 从源码构建

使用与 CI 一致的 Node.js 22 和 npm，在项目根目录执行：

```bash
npm ci
npm --prefix mcp-server ci
npm run mcp:build
npm run build
```

加载 `dist/`。需要接入 MCP 时，在同一台电脑和项目目录执行：

```bash
npm run mcp:config
```

将生成的 `page-agent` 条目合并到客户端的 `mcpServers`。服务入口为 `mcp-server/dist/index.js`，不能填写 TypeScript 源文件，也不将 WebSocket 地址当作客户端 HTTP MCP 地址。源码环境配置本机启动器的方法在插件高级设置与 [跨系统部署](../cross-platform-mcp.md) 中说明。

## 升级并确认生效

1. 导出重要工作流；确认没有工作流或后台录制正在运行。
2. 替换原目录内容，或解压并加载新目录；完整包换目录时运行新包 Setup。
3. 在扩展管理页重新加载，重新打开侧栏核对实际版本；刷新业务网页以更新内容脚本。
4. 同步更新客户端路径，并在 MCP 面板核对实际运行服务路径与版本。仅重启 stdio 客户端可能仍连接旧共享 broker，需在确认空闲后停止旧 broker 并重新连接。
5. 异步录屏要求扩展 0.10.76+、MCP 0.10.21+；对已播放但持续加载的直播页，应使用已修复开始等待的扩展 0.10.77。

“重新加载”仍使用原目录，不会自动切到新下载目录。同一扩展身份与 Chrome 配置文件内的数据通常保留；卸载、换配置文件或改变扩展身份可能看不到原数据，应先导出备份。

## 安装完成检查

- 侧栏能打开，实际版本与预期一致。
- 可以创建工作流并看到开始节点，在练习页完成选择、运行和保存。
- 需要 MCP 时，插件显示已连接，客户端可以列出正确实例。
- 需要录屏时，先打开具体直播页、点击工具栏图标，确认画面播放和网页声音。
