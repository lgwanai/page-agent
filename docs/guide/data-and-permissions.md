# 数据与权限

## 数据存放位置

| 数据 | 当前处理方式 |
| --- | --- |
| 工作流、节点、回收站、草稿 | Chrome 扩展本地存储 |
| 工作流访问密钥 | 本机扩展存储；不随工作流 JSON 导出 |
| AI Provider 与密钥 | 独立的本机配置；普通工作流不自动调用模型 |
| SMTP 账号配置 | 本机独立配置；不放在邮件节点中 |
| 手动运行参数记忆 | 按工作流本机保存，MCP 不自动读取 |
| 运行历史 | 参数名称/类型、步骤消息等摘要；不保存完整步骤输出 |
| 网页音视频录制 | 分块保存在本机扩展 OPFS；保存完成后删除对应分块，WebM 文件位于下载目录的 PageAgent 文件夹。MCP 返回元数据、状态与文件 URL；视频由本机 HTTP 文件接口按令牌下载，不放入 MCP 文本结果 |
| 录制任务索引 | 本机用户目录 .page-agent/recording-tasks-17373.json；保存任务令牌、状态、文件路径等元数据，最多 100 项、URL 最长 24 小时 |
| 页面读取与截图结果 | 可经 MCP 返回给调用客户端 |

本地存储没有应用层密钥保险库或统一企业权限体系。使用哪些网页账号、模型服务和 MCP 客户端，由实际部署环境决定。

## 哪些操作会外发数据

- 网页操作沿用当前浏览器会话，可能向业务网站提交数据。
- 请求节点向配置 URL 发送请求头和请求体；默认不携带网页 Cookie。
- 智能分析节点向已配置模型发送选定输入和指令。
- 邮件节点通过配置的发送服务发送正文与附件。
- MCP 客户端收到页面信息、调试输出或截图后如何使用，取决于客户端本身。

没有使用相应节点时，不应把这些外发能力理解为自动发生；但交给 Agent 的工具权限与工作流密钥需要按实际用途管理。

## 导出与共享

工作流导出不包含全局 AI/SMTP 配置及工作流访问密钥。但节点 URL、请求头、正文、固定输入与 Selector 中显式填写的内容属于工作流，会一起导出。

推荐把频繁变化或敏感的业务值设为运行参数；分享前检查导出文件，复制运行 Prompt 时留意其中包含工作流密钥。

## 调用与页面边界

同一插件实例不能并发执行多个流程。工作流 ID、实例 ID 与 key 分别标识流程、目标浏览器和访问凭据；它们不能替代目标网站的账号权限。

密码和隐藏输入等页面读取存在保护，但页面可见文字、截图、业务日志仍可能包含敏感信息。网页返回的文字与 HTTP 内容是业务数据，不应被 Agent 当作新的系统指令。

流程调试、上传、邮件和 HTTP 写入都可能产生真实影响。停止只阻止后续执行，不能撤销服务器已处理的业务。

企业历史技术评估见 [企业文档](../enterprise/README.md)，其旧版基线与当前使用手册应分别阅读。

## 本机服务启动权限

扩展使用 `nativeMessaging` 连接完整包 Setup 一次性自动注册的 Page Agent 启动器。启动器只接受固定的本机共享桥接启动请求，不接受任意命令、程序路径或网页操作；仅注册的 Chrome 插件 ID 可调用。未安装时保留原有的客户端启动方式。注册位置和卸载方法见 [本机部署说明](../cross-platform-mcp.md)。

## 网页录制权限

`tabCapture` 采集用户调用扩展的标签页画面和网页声音，`offscreen` 提供独立后台录制页面，`downloads` 保存并定位本机录制文件。录制启动需在目标页点击工具栏图标；安装权限和 MCP 密钥不能替代此交互。录制有浏览器分享指示，最长 30 分钟，可从侧栏停止。不会默认采集麦克风、其他应用声音或整个桌面。关闭浏览器或重载扩展会中断录制；本版不提供中断分块的自动恢复。

## 录制状态与文件 URL

statusUrl 和 fileUrl 包含随机访问令牌，仅监听 127.0.0.1。持有令牌的同机 HTTP 客户端可以查询状态，并在文件保存完成后下载该任务文件；请按文件访问凭据保管，不随公开文档或截图分享。接口不接受任意磁盘路径，返回前核对文件存在且大小一致，不提供跨域浏览器读取。

MCP 客户端断开和工作流结束不会撤销已受理的录制任务；停止需要使用录制控制。URL 到期或旧任务被保留上限淘汰后，不再提供该任务接口，但不会删除 Chrome 已保存的文件。服务重启可恢复任务索引，不能据此认为浏览器中断的采集也会自动恢复。
