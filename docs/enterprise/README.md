## 一页理解

Page Agent 是运行在用户 Chrome 配置文件中的网页工作流执行器。用户通过录制或画布配置将网页操作保存为节点图；Agent 可以通过本机 MCP 创建、编辑、读取、调试和执行工作流。确定性节点由插件执行，只有 AI 节点调用配置的模型接口。

它不要求改造目标网站，也不需要目标系统提供 API。执行沿用浏览器当前登录态和业务权限，因此也继承目标网站的访问控制、页面结构变化、网络状态及人工登录限制。

### 企业必须知道的五个边界

1. **本地优先不是数据绝不外发。** MCP 会返回页面、日志和截图；AI 节点会向配置的模型接口发送输入。MCP 客户端自身是否把这些数据上传模型，属于另一条必须审核的数据链路。
2. **工作流 key 不是完整企业授权。** 它保护指定工作流的一组接口，但旧版 workspace/Action 接口，以及新建、导入入口并没有统一的调用方鉴权。
3. **本地密钥没有应用层加密。** API Key、工作流 key 和手动运行历史使用 Chrome 扩展本地存储，不是企业密钥保险库。
4. **DOM 校验不等于业务交易确认。** 输入值比对、点击事件与页面变化能确认部分交互事实，不能证明订单提交、报表生成等服务器端业务结果。
5. **当前不是多租户企业平台。** 尚无组织账号、RBAC、审批、域名级操作策略、持久化审计平台和集中策略管理。

建议把当前版本定位为受管终端上的网页自动化工具，先在隔离配置文件和低风险流程中试点；是否进入敏感生产业务，应依据安全文档中的缺口和上线检查结果决定。
