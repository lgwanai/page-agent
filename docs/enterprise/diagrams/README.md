# 架构图资源

| 图 | 用途 | 可编辑矢量源文件 |
| --- | --- | --- |
| 系统架构与数据边界 | 客户架构/安全评估：部署位置、通信协议、三条外发链路 | [SVG](system-architecture.svg) / [PNG](system-architecture.png) |
| 组件模块与职责分层 | 技术评估：模块责任、实现文件、层间依赖 | [SVG](component-modules.svg) / [PNG](component-modules.png) |

SVG 是正式源文件，包含可编辑文字、分组、连线、标题和无障碍描述，适合浏览器放大、打印和演示文档导入；配套 PNG 用于不支持 SVG 的查看器。中文优先使用苹方、微软雅黑、Noto Sans CJK SC，缺少字体时需安装相应中文字体。

配色约定：蓝色分组为浏览器配置文件/交互层，浅灰为本机服务/后台/基础模块，浅绿为页面能力，浅暖色为独立服务。虚线箭头表示独立服务链路，不表示默认一定访问公网；企业内网模型网关也属于需要另行审核的服务。

图中只展示当前存在的组件，不将统一认证、策略引擎、集中审计和审批等建议能力画为已实现模块。更新架构时应同时核对 [architecture.md](../architecture.md) 与 [data-security.md](../data-security.md)。
